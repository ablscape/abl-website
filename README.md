# ABL Landscape Architecture website

The source of ablscape.com. Plain HTML and CSS, generated by one script from a text file per project. Nothing to install and nothing to update.

- **Editing the site:** see [EDITOR-GUIDE.md](EDITOR-GUIDE.md). Changes are made by asking Claude.
- **Rules Claude follows:** see [CLAUDE.md](CLAUDE.md). Claude reads it at the start of every session.

## How it fits together

| Piece | Job |
|---|---|
| This repository (GitHub) | The single source of the site. Every change is a pull request. |
| Netlify | Builds a preview for each pull request and publishes `main` to the live site. |
| Claude | Edits the files in `content/`, opens the pull request, merges on "publish". |
| GoDaddy | Domain registration, DNS and Microsoft 365 email. The website needs two DNS records there and nothing else. |

## Layout

```
content/
  site.json              firm details, home page, People page text, Process page, contact form choices
  people.json            the People page
  legacy-urls.json       addresses from the old site, forwarded to new pages
  projects/<slug>/
    project.json         one project: facts, story, photo list
    photos/              01-640.jpg, 01-1280.jpg, 01-1920.jpg, 01-2560.jpg ...
static/                  copied as is: stylesheet, script, fonts, logo, portraits
templates/               one file per kind of page
lib/                     loading, checking, image sizes
build.js                 the builder
tools/prepare_photos.py  resizes photographs, converts to sRGB, strips location data
netlify.toml             build settings
```

## Building

Needs Node 18 or later. No `npm install`.

```
node build.js               # preview view: drafts and gray notes included
node build.js --production  # live-site view: published projects only
node build.js --check       # list everything unfinished
node build.js --portable    # preview/ folder that opens from disk, for sending to someone
node build.js --no-notes    # drafts included, notes left out: the design as it will look
```

The build stops with a plain-language list if content is malformed, a photograph is missing, or a link leads nowhere.

`netlify.toml` builds the live site with `--production`, so drafts and preview notes cannot reach it. Pull request previews use the plain build and show them.

## Design settings

Colors, typefaces and the four text sizes are variables in the first block of `static/assets/css/site.css`. Every rule takes its size from one of the four names, and a heading is never smaller than the text it stands over. The page is a toned sheet, an off-white with a little gray-green in it, like drafting paper (`--paper`, with the same color as three numbers in `--paper-rgb`); on it stand near-black type, the green of the logo, a deep green for the block at the foot of every page (`--deep`), and one warm accent (terracotta) for short rules, numerals and links on hover. The sheet is never cream or yellow. Preview notes are gray, so that they lend the pages no color while the design is judged; they never appear on the live site. No gray on the site is warm. The typeface is Barlow throughout, in four weights, self-hosted under the SIL Open Font License; the firm may name the typeface from its drawings to replace it.

The firm's hand drawings are the theme of the site, and its restraint is deliberate: no video, no movement or effect that draws attention to itself. A drawing lies behind the home-page statement and behind the heading of the Work, People, Process and Contact pages (`backdrop` in `content/site.json`), three stand in a row lower on the home page (`drawings`), and a project may lead with a drawing (`cover`). A drawing behind a heading is shown as ink on the page: it has no frame and no band, a drawing made on gray paper has its paper brought to white first (`lift`), and it dissolves into the page above, below and toward the text. On a wide screen the text lies at the left, over the drawing's faded side or beside the drawing (`from`); on a phone or a tablet the text comes first and the drawing follows. Nothing moves. A drawing behind a heading is turned a few degrees from yellow toward green (`--plan-key` in the stylesheet) unless its entry says `asDrawn`. The same drawing keeps its own colors on its project page and wherever else it appears.

Every drawing takes the sheet as its paper (`[data-sheet]` in the stylesheet: the drawing is multiplied into the page's color), so it reads as ink on the page with no rectangle around it. A drawing stands where a page begins, behind its heading, and a project shows its own plans between its opening and its photographs; a plan can stand beside the photograph of what was built from it (`built` in the drawing's entry). Process keeps one drawing, at its head, and the Dialogue diagram. Tried and taken out: a page-wide ground of traced linework (round 14), which turned a drawing into a pattern, and a drawing at the foot of every page (round 15), which read as decoration.

Projects are listed two to a line, on the Work page and under "Selected work" on the home page, inside the page's margins: the picture, then the kind of project, its name, and its place. One project alone from edge to edge was tried in round 16 and read as too large and "too zoomed in", the more so because most of the files are 1,280 pixels wide; two to a line shows them at about their true size on a laptop. Every photograph on a project page, the lead photograph included, keeps the margins and its own proportions. Only the home slideshow runs from edge to edge, and it keeps the photographs' proportions unless the window is too short. `main` clips sideways overflow, so that nothing reaching past the margins can make the window scroll sideways.

The heading of each page is a low block with the title and a short opening at the left and a drawing behind. On a wide screen the drawing runs up behind the header to the top of the window (`--head-h` is the header's height), so the page begins with the drawing; the logo lies on a soft patch of the sheet's color that has no edge, and the links carry the haze the traveling mark has. A heading carries its title and at most a short opening; the People page's introduction stands below its heading.

Once the header has scrolled away, the "abl" of the logo stays at the top right of the window, green over the page and over drawings and white over photographs, and the links return when the visitor scrolls up. Where it is green the mark carries a soft white haze, so that text or linework passing beneath fades out around the letters; a picture marked `data-photo` or `data-sheet` in the templates carries its own copy, clipped to its frame. The returning links are drawn the way the mark is: dark, in medium weight, on a patch of white haze over the page and over drawings; white with a close dark shadow over photographs. A page reached by a link always opens at its top, whatever the browser or the window showing the site does with the old position (a script in the head of every page sees to it; going back or forward keeps the browser's own place). The mark is a vector redrawn from the 230-pixel logo and fitted to it by measurement (`MARK_PATH` in `lib/html.js`). The header logo, `static/assets/img/logo.svg`, is a drawing too: the same mark, with the two words set in Crimson Text (an open-licensed typeface chosen as the nearest of ten compared against the old file) and converted to outlines, so it stays sharp on every screen and loads no font.

## Before launch

- [ ] Replace the redrawn logo with the firm's own artwork (AI, EPS, PDF or SVG from whoever designed it). `static/assets/img/logo.svg` is a redrawing; `logo.jpg` beside it is the 230-pixel file from the old site that it was drawn from, kept for reference.
- [ ] Rescan the hand drawings at full size and prepare them again: those on the site are 1280 pixels wide, and they stand behind every heading and at the foot of every page, where a large screen shows them soft.
- [ ] `node build.js --check` reports nothing unfinished that matters.
- [ ] Turn on form detection in Netlify (Forms) and set the notification email for the `inquiry` form.
- [ ] Delete the `X-Robots-Tag` block in `netlify.toml`.
- [ ] In Netlify, add `www.ablscape.com` as the primary domain. At GoDaddy, edit the existing A record for `@` to Netlify's load balancer address and change the `www` CNAME to the Netlify site address. Netlify's domain panel shows the exact values. Leave the MX, autodiscover and TXT records untouched: they carry the firm's email.
- [ ] Keep the old GoDaddy hosting for a month as a fallback. Then cancel that product only, after confirming the Microsoft 365 email is billed separately.
